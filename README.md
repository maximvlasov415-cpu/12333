# Павлик — чат-бот-мудак для Telegram

Павлик сидит в чате с пацанами, читает переписку и отвечает, когда его зовут по имени,
тегают или отвечают на его сообщение. Периодически влезает сам и подъёбывает того,
кто что-то написал. Фирменная фишка — коверкать слова на «-ин»:
«Я пошёл обедать» → «Ты обедин чтоли».

Что ещё умеет:

- отвечает на любой вопрос по существу — но со своим ядом. Спросили по-человечески —
  ответит нормально, нахамили — пошлёт;
- запоминает участников: копит темы, которые человек мусолит, и тезисы вроде
  «его все зовут дураком». Потом использует это в подъёбках — Максиму, который вечно
  про бутерброды и пабг, предложит сделать бутер с говном после победы.

Работает на любой **бесплатной** модели с OpenAI-совместимым API: Groq, Google Gemini,
OpenRouter (модели `:free`) или локальная Ollama. Платить за токены не нужно.

## Установка

```bash
git clone <этот репозиторий>
cd 12333
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Настройка

### 1. Бот в Telegram

1. Пишешь [@BotFather](https://t.me/BotFather), команда `/newbot`, получаешь токен → в `.env` в `TELEGRAM_BOT_TOKEN`.
2. **Обязательно** отключаешь privacy mode, иначе бот не увидит сообщения в группе:
   `/mybots` → твой бот → `Bot Settings` → `Group Privacy` → `Turn off`.
3. Добавляешь бота в чат с пацанами.

### 2. Бесплатная модель

Выбери один вариант и раскомментируй его в `.env`:

| Провайдер | Ключ | Модель | Что по лимитам |
|---|---|---|---|
| **Groq** (по умолчанию) | [console.groq.com/keys](https://console.groq.com/keys) | `llama-3.3-70b-versatile` | бесплатно, очень быстро, лимит по запросам в минуту |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | `gemini-2.0-flash` | бесплатный тариф, лучше всех шарит за русский |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | любая с суффиксом `:free` | бесплатно, выбор моделей больше |
| **Ollama** (локально) | не нужен | `qwen2.5:14b` и т.п. | бесплатно совсем, нужен свой комп с видюхой |

Часть моделей упирается в цензуру и отказывается материться. Если бот отвечает
вежливо или молчит — меняй модель: у OpenRouter и в локальной Ollama с этим проще,
чем у Gemini.

### 3. Поведение

В `.env`:

- `BOT_NAMES` — имена и основы имён, на которые бот откликается. Падежи ловятся сами:
  `павл` поймает «Павла» и «Павлу», `паш` — «Пашу», «Пашке», «Пашей».
- `RANDOM_REPLY_PROBABILITY` — вероятность влезть в разговор без обращения (`0.08` ≈ каждое 12-е сообщение).
- `RANDOM_REPLY_COOLDOWN` — сколько секунд молчать после такой вылазки, чтобы не задолбал.
- `JOKE_PROBABILITY` — доля ответов с фишкой на «-ин» (`0.15` ≈ каждый седьмой).
  В остальных ответах модели прямо запрещено коверкать слова.
- `HISTORY_LIMIT` — сколько последних сообщений чата уходит в контекст модели.
- `ALLOWED_CHAT_IDS` — если заполнить, бот работает только в этих чатах.
- `PROFILE_UPDATE_EVERY` — раз во сколько сообщений обновлять досье на участников.
  Досье лежит в `profiles.json` (`PROFILE_PATH`) и переживает перезапуск.

## Запуск локально

```bash
python -m bot
```

## Запуск на сервере (Ubuntu/Debian, systemd)

На сервере:

```bash
git clone -b claude/friendly-fermi-u80hzg https://github.com/maximvlasov415-cpu/12333.git pavlik
cd pavlik
sudo bash deploy/install.sh
```

Скрипт поставит зависимости, заведёт системного пользователя `pavlik`, разложит бота
в `/opt/pavlik`, спросит токен бота и ключ Groq (ввод скрытый, попадает только в
`/opt/pavlik/.env` с правами 600) и поднимет сервис с автозапуском.

Ключи можно передать сразу, без ввода руками:

```bash
sudo TELEGRAM_BOT_TOKEN='токен' LLM_API_KEY='ключ' bash deploy/install.sh
```

| Что нужно | Команда |
|---|---|
| Логи | `journalctl -u pavlik -f` |
| Перезапуск | `sudo systemctl restart pavlik` |
| Настройки | `sudo nano /opt/pavlik/.env`, потом перезапуск |
| Обновить бота | `git pull` в папке репозитория и снова `sudo bash deploy/install.sh` |

Повторный запуск скрипта — это обновление: код перезаливается, а `.env` и накопленное
досье `profiles.json` остаются на месте.

Сменить токен или ключ: правишь `/opt/pavlik/.env` и делаешь `systemctl restart pavlik`.

Проверить, жив ли доступ к модели: напиши в чате `/ping` — бот ответит либо словом
от модели, либо точной причиной отказа.

Сменить модель (например, провайдер снял старую с обслуживания):

```bash
bash deploy/set_model.sh                 # покажет список и выберет годную сам
bash deploy/set_model.sh qwen/qwen3-32b  # или поставит конкретную
```

Кандидаты проверяются тремя живыми вопросами (факт, счёт, связная русская фраза) —
модель, которая не тянет русский, до бота не доходит.

Сменить провайдера, если у текущего нет годных моделей (пример — Gemini):

```bash
python3 deploy/envtool.py set LLM_BASE_URL https://generativelanguage.googleapis.com/v1beta/openai
python3 deploy/envtool.py set LLM_API_KEY 'ключ из aistudio.google.com/apikey'
bash deploy/set_model.sh
```

## Если что-то не работает

| Симптом | В чём дело |
|---|---|
| В группе молчит, в личке отвечает | Не выключен Group Privacy у @BotFather — бот не видит чужие сообщения |
| В логах `401 Unauthorized` | Протух или неверный токен бота |
| В логах `LLM ответил 401` | Неверный ключ модели в `LLM_API_KEY` |
| В логах `LLM ответил 429` | Упёрлись в бесплатный лимит провайдера, подожди или смени модель |
| В логах `404 model_not_found` | Провайдер снял модель с обслуживания — `bash deploy/set_model.sh` подберёт живую |
| Павлик несёт бессвязную кашу | Подобралась слабая или нерусскоязычная модель — `bash deploy/set_model.sh` проверяет кандидатов вопросом по-русски и берёт того, кто ответил внятно |
| `/ping` говорит «ушла в рассуждения» | Выбрана reasoning-модель: она тратит токены на размышления и отдаёт пустой текст. `bash deploy/set_model.sh` возьмёт болталку, либо подними `LLM_MAX_TOKENS` |
| Отвечает вежливо, без мата | Модель зацензурена — меняй `LLM_MODEL`/провайдера |

## Как это устроено

| Файл | Что делает |
|---|---|
| `bot/handlers.py` | решает, отвечать ли: обращение по имени, тег, реплай или случайная подъёбка |
| `bot/persona.py` | характер бота и шаблоны промптов |
| `bot/wordplay.py` | генератор шуток на «-ин»: режет окончание и лепит основу + `ин` |
| `bot/llm.py` | запрос к OpenAI-совместимому API, чистка ответа от `<think>` и отказов |
| `bot/memory.py` | последние сообщения по каждому чату |
| `bot/profiles.py` | досье на участников: темы из их сообщений + тезисы, хранится в JSON |
| `bot/profiler.py` | раз в N сообщений просит модель обновить тезисы про пацанов |

Заготовка на «-ин» считается в коде и подсовывается модели подсказкой — так шутка
получается из реального слова в сообщении, а не выдумывается моделью с нуля.
Если модель не ответила или включила цензуру, бот отвечает заготовкой сам.

## Границы

В характере бота прописано: стёб только по поводу написанного, без травли по
национальности, вере, ориентации и здоровью, без угроз, и с выключением режима мудака,
когда в чате обсуждают что-то серьёзное.
