# RoastBot

Телеграм-бот для группового чата: с небольшой случайной вероятностью на любое
сообщение отвечает грубой/матерной подколкой, сгенерированной бесплатной LLM
(Groq, модель Llama). Между выходками в одном чате выдерживается кулдаун,
чтобы не спамить.

## 1. Получить токен бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram.
2. `/newbot`, задайте имя — получите `BOT_TOKEN`.
3. У BotFather выполните `/setprivacy` → выберите бота → `Disable`.
   Это обязательно: без отключения privacy mode бот не будет видеть чужие
   сообщения в группе, а только команды и сообщения, адресованные ему.

## 2. Получить бесплатный ключ Groq

1. Зайдите на https://console.groq.com/keys, зарегистрируйтесь.
2. Создайте API-ключ — это `GROQ_API_KEY`. Бесплатного лимита достаточно для
   такого бота (он дергает LLM редко, только когда сработал случайный шанс).

## 3. Настройка

```bash
cp .env.example .env
# впишите BOT_TOKEN и GROQ_API_KEY в .env
```

Параметры в `.env`:

- `TRIGGER_CHANCE` — вероятность (0–1) ответить грубостью на очередное
  сообщение в чате. По умолчанию `0.04` (~4%).
- `COOLDOWN_SECONDS` — минимальный интервал между выходками бота в одном
  чате, в секундах. По умолчанию 600 (10 минут).
- `GROQ_MODEL` — модель Groq, по умолчанию `llama-3.3-70b-versatile`.

## 4. Запуск

### Вариант А: Docker (рекомендуется)

```bash
docker compose up -d --build
```

### Вариант Б: напрямую

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

### Вариант В: systemd (постоянная работа на сервере)

1. Скопируйте проект в `/opt/roastbot`, создайте venv и поставьте зависимости
   как в варианте Б.
2. Создайте пользователя `roastbot` (или замените `User=` в юните на своего).
3. Скопируйте `deploy/roastbot.service` в `/etc/systemd/system/roastbot.service`.
4. `sudo systemctl daemon-reload && sudo systemctl enable --now roastbot`

## 5. Добавление в чат

Добавьте бота в групповой чат как обычного участника — прав администратора
не требуется.

## Как это работает

- На каждое текстовое сообщение в группе бот с вероятностью `TRIGGER_CHANCE`
  генерирует ответ через Groq (стилизован под грубую дружескую подколку,
  с матом) и отвечает на это сообщение.
- Действует кулдаун `COOLDOWN_SECONDS`, чтобы бот не срабатывал слишком часто
  в активном чате.
- Промпт специально ограничен дружеским стёбом: без реальной ненависти,
  оскорблений по защищённым признакам (национальность, религия и т.п.),
  угроз и тем самоповреждения — только грубый бытовой троллинг.

## Важно

Это шуточный бот для приватного чата, где все участники в курсе и согласны
на такой формат общения. Не добавляйте его в чаты, где люди не давали
согласия получать грубые сообщения.
